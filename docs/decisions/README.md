# Decision records

This directory holds Architecture Decision Records (ADRs) — short
documents describing significant technical choices, the alternatives
that were considered, and the reasoning.

## Index

- [0001 — Record architecture decisions](0001-record-architecture-decisions.md)

## Writing a new ADR

Copy the most recent record, increment the number, and fill in the
sections. Keep them short (one page). Once merged, ADRs are immutable
— if the decision is later overturned, write a new ADR that supersedes
the old one and link from both directions.
