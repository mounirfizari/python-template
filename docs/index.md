# python-template

<!-- One-paragraph description of the project. What is it, who is it for. -->

A template for modern Python projects.

## What's inside

- Modern Python packaging with [uv](https://docs.astral.sh/uv/)
- Ruff for linting and formatting, mypy in strict mode
- Pre-commit hooks and a CI workflow that enforce both
- A test scaffold with pytest and coverage
